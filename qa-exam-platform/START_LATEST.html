QA Exam Platform

Latest build: post-publication score editing enabled.

Start the app

  1. Keep this file in the project folder.
  2. Double-click START_LATEST.bat.
  3. The script runs npm install and then npm run dev.
  4. Open the localhost URL printed by Next.js.

Post-scored editing

Auditors can open a published scorecard, choose Amend Scorecard, edit scores/comments/knowledge gaps, and save the correction. Score changes require a reason and are retained in score history.
